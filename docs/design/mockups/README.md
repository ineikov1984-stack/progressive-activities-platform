# Одобрени макети

Това са макетите, одобрени от собственика. Те са копие на дизайн платното „Присъствия — макет“ в Claude, изнесено като самостоятелен HTML и PNG. В тях има само синтетични данни.

**Правила за ползване:**
- Строиш екрана по PNG-то. Точните български текстове взимаш от HTML-а.
- Цветовете в макетите са hex. В кода се ползват **само** токените от `platform/apps/web/src/design-system/tokens.css` (AGENTS.md).
- Бележките в макета, написани с по-малък сив текст под карта, са обяснения за собственика. Те не са текст за екрана.
- Нов екран без макет тук не се прави. Спри и запиши въпрос в WORKBOARD → „Въпроси към собственика“; Claude прави макета (WORKFLOW т. 3).
