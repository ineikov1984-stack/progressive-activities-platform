# Дизайн система в кода

`tokens.css` е огледало на одобрената дизайн система „Progressive Activities“ (цветове, отстояния, ъгли, сенки, размери, шрифт). Зарежда се глобално от `app/globals.css`, шрифтът Onest — от `app/layout.tsx` чрез `next/font` (сервира се от нашия домейн, затова CSP остава `font-src 'self'`).

Правила (пълните са в `AGENTS.md` → UI/UX и в артефакта на дизайн системата):

- В CSS модулите се ползват само `var(--…)` от `tokens.css`; нови hex стойности не се добавят.
- Текст: `--ink` за заглавия, `--ink-body` за абзаци, `--ink-muted` за помощен текст.
- Основно действие: `--action` (бял текст). `--brand` е само за акценти, никога за текст на светъл фон.
- Статуси: `--status-*` с `-soft` подложка; винаги с дума, не само с цвят.

Защо не е в `platform/packages/design-system`: засега има един потребител (web). Пакетът ще се отдели, когато се появи втори (мобилни приложения), заедно с промяната в pnpm workspace и Docker контекста.
